# Чек-лист проектной работы

| Требование | Где реализовано | Как работает |
| --- | --- | --- |
| Общая конфигурация API и обработка ошибок | `src/scripts/api.js` | Токен и JSON-заголовок добавляются в каждый запрос; неуспешный ответ превращается в понятную ошибку. |
| Загрузка профиля и карточек | `src/scripts/main.js` | `Promise.all` загружает `/users/me` и `/cards`; карточки и профиль выводятся после ответа. |
| Редактирование профиля | `api.js`, форма `#profile-form` | `PATCH /users/me`; интерфейс обновляется данными ответа. |
| Обновление аватара | `api.js`, форма `#avatar-form` | `PATCH /users/me/avatar`; новый аватар берётся из ответа сервера. |
| Добавление карточки | `api.js`, форма `#card-form` | `POST /cards`; новая карточка добавляется первой в сетке. |
| Удаление только своей карточки | `src/scripts/card.js`, обработчик в `main.js` | Кнопка удаления создаётся только при совпадении `owner._id` и ID текущего пользователя. Запрос выполняется после подтверждения. |
| Лайки и счётчик | `api.js`, `src/scripts/card.js` | `PUT` ставит лайк, `DELETE` снимает. После ответа обновляются сердечко и число лайков. |
| UX отправки форм | `src/scripts/main.js` | Кнопки показывают состояния «Сохранение…», «Создание…» и «Удаление…»; при ошибке появляется сообщение. |
| Вариант 3 — статистика карточек | Окно `#stats-popup`, `getCardStatistics` в `main.js` | Логотип загружает актуальные карточки и считает владельцев, лайки, чемпиона по числу карточек с лайком и топ-3 карточек. |
| Совместимость GitHub Pages | `vite.config.js`, `.github/workflows/deploy.yml` | Относительный путь сборки и автоматическая публикация `dist` в целевой публичный репозиторий. |
| Дополнительные действия из макета | `index.html`, `main.js`, `src/styles.css` | Есть предпросмотр фотографии, сведения о карточке, подтверждение удаления и мобильная раскладка. |

Данные API не подменяются демонстрационными, когда конфигурация заполнена. Демонстрационные карточки используются только пока отсутствуют данные API — для просмотра вёрстки и статистического окна без личного токена.
