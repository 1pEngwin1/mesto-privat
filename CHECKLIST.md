# Чек-лист проектной работы

| Требование | Где реализовано | Как работает |
| --- | --- | --- |
| Запросы к API и обработка ошибок | `src/scripts/components/api.js` | Общий запрос добавляет заголовки и превращает неуспешные ответы в ошибки. |
| Профиль и карточки с сервера | `src/scripts/index.js` | Профиль и карточки запрашиваются параллельно и отображаются по ответам API. |
| Валидация полей форм | `src/scripts/components/validation.js` | Проверяются обязательность и длина полей, формат ссылок и допустимые символы имени. |
| Запрет цифр в имени профиля | `validation.js`, поле `#profile-name-input` | Ввод и вставка недопустимых символов блокируются; обработчик `input` служит дополнительной защитой. |
| Кнопка профиля до изменения | `validation.js`, `index.js` | Кнопка включается только если данные корректны и имя или описание отличаются от исходных. |
| Ошибки и состояния отправки | `validation.js`, `index.js` | Ошибки показываются у полей; во время запросов кнопки показывают «Сохранение…» или «Создание…». |
| Модальные окна | `src/scripts/components/modal.js` | Открытие, закрытие по крестику, фону и Escape вынесено в отдельный модуль. |
| Карточки, лайки и удаление | `src/scripts/components/card.js`, `index.js` | Лайки синхронизируются с API; удалить карточку может только её владелец. |
| Вариант 3 — статистика карточек | `src/scripts/index.js` | По нажатию на логотип отображаются данные о карточках и лайках. |
| GitHub Pages | `vite.config.js`, `.github/workflows/deploy.yml` | Workflow из приватного репозитория публикует только содержимое `dist` в публичный Pages-репозиторий. |
| Мобильная форма без горизонтальной прокрутки | `src/styles.css` | Контейнер модального окна скрывает горизонтальное переполнение, поля занимают доступную ширину. |
